# Photos

Drop real photos here using **exactly** these filenames. Each one automatically
replaces its illustration on the site, with no code changes needed.

| File | Where it shows | Best shape |
|---|---|---|
| `hero.jpg` | Big round plate in the hero | Square, top-down plate shot |
| `coconut-milk-pepper-rice.jpg` | Wednesday special | Square or 4:3 |
| `garifotor.jpg` | Thursday special | Square or 4:3 |
| `jollof.jpg` | Friday special | Square or 4:3 |
| `melanin-box.jpg` | Melanin Box card | Landscape ~16:11, box open from above |
| `mini-melanin-box.jpg` | Mini Melanin Box card | Landscape ~16:11 |
| `tiktok-1.jpg` `tiktok-2.jpg` `tiktok-3.jpg` | The three phone mock-ups | Portrait 9:16 (video thumbnails) |

Tips: keep each file under ~300 KB (1200px on the long side, quality 80
is plenty). Use `.jpg` exactly as named above. To use other names or `.webp`, change
the `photo:` paths in `js/menu.js` (and `data-photo` in `index.html` for the
hero and phone images).
